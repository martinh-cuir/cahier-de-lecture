Clé d'API Claude

Elle permet l'idée maîtresse, la lecture des photos et les thèmes croisés. Créez-la sur la console Claude (platform.claude.com, rubrique API Keys). Elle reste dans ce téléphone et n'est envoyée qu'à Anthropic. L'usage est facturé sur votre compte API, en dehors de votre abonnement Claude.

Vos données

Vos fiches sont enregistrées dans ce téléphone, et nulle part ailleurs. Sauvegardez régulièrement : une sauvegarde se restaure ici ou dans le Cahier de lecture de Claude.

Installer l'application

Dans Chrome, ouvrez le menu ⋮ puis « Installer l'application » ou « Ajouter à l'écran d'accueil ».
